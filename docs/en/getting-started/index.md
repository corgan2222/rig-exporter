# Getting started

The way from the downloaded file to the device in Home Assistant. Two pages,
to be read in this order:

<div class="grid cards" markdown>

-   :material-check-circle-outline: **[Requirements](../requirements.md)**

    What is really needed — namely almost nothing — and which extra program
    unlocks which area.

-   :material-rocket-launch-outline: **[First start](../first-run.md)**

    Autostart, configuration file, language. What happens on the first double
    click and where things are afterwards.

</div>

For those in a hurry: download, start, and under
[**Export & display → MQTT**](../interface/export-and-display.md#mqtt-push-to-home-assistant)
enter the MQTT broker. Everything else has a usable default.

After that it continues under [Interface](../interface/index.md) — every
setting is listed there with its default.
